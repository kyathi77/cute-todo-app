🌸 Cute To-Do List App 🌸  

A simple and adorable to-do list app built with Flask. Designed with a girly pop aesthetic featuring pastel colors and smooth animations.  

## 💖 Features  
✅ Add, edit, and delete tasks  
✅ Filter tasks by category (Work, Personal, Shopping, etc.)  
✅ Smooth, cute UI with pink and pastel colors  

🚀 Installation  
1. Clone the repo:  

git clone https://github.com/kyathi77/cute-todo-app.git

2. Install dependencies:  

pip install -r requirements.txt

3. Run the app:  

python3 app.py

🛠️ Technologies  
- Python  
- Flask  
- HTML/CSS
